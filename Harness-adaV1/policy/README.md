# Policies

Regras globais do harness. Valem para todo papel, workflow e skill.

**Regra repetida em mais de uma skill vira policy**: a skill só linka. Assim a regra tem uma definição só.

| Policy | Assunto |
|---|---|
| [quality](quality.md) | validar antes de concluir, escopo explícito, evidência acima de suposição |
| [auto-validation](auto-validation.md) | validar localmente antes de devolver a etapa |
| [editing](editing.md) | edição mínima e dentro do escopo |
| [research](research.md) | pesquisa externa com fonte e domínios permitidos |
| [security](security.md) | segredos, acesso e ações externas |
| [idioma](idioma.md) | idioma de texto, código e commits |

Formato: [_modelo.md](_modelo.md).
