# Workflows

Processos de ponta a ponta: sequência de etapas, papéis, capabilities e skills, gates e critério de conclusão.
Workflow é orquestração, não conhecimento de implementação. Formato: [_modelo.md](_modelo.md).

| Workflow | Objetivo |
|---|---|
| [coordination](coordination.md) | escolher o workflow e conduzir qualquer pedido |
| [feature](feature.md) | entregar uma feature: plan → tests → revisão dos testes → implement → audit → review |
| [delegation](delegation.md) | levar problema estrutural ao papel platform |

Moldes dos artefatos da feature: [feature-artefatos/](feature-artefatos/README.md).
