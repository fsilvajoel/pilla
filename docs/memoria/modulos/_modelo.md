# Módulo `<module>` (ficha)

> ≤ 300 palavras. Atualizar no mesmo PR que muda a API pública ou um invariante.

- **Propósito:** uma frase.
- **Regras que implementa:** IDs (ex.: RN-C03, RF-20).
- **API pública** (`public/`): funções/eventos expostos.
- **Invariantes:** o que nunca pode acontecer.
- **Eventos:** publica / consome.
- **Mapa de arquivos:** onde está o quê.
- **Armadilhas:** links para `licoes.md`.
