## Configuração

As configurações e segredos ficam em variáveis de ambiente, num arquivo `.env` que não vai para o git.

```bash
cp .env.example .env
chmod 600 .env
# edite o .env e preencha os valores reais
```

O `.env.example` lista todas as variáveis com valores de exemplo; ao criar uma variável nova, inclua-a nele.
